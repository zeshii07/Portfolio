# Portrait images

Drop your portrait PNGs in this folder. Two slots are supported:

## 1. Hero portrait (transparent background cutout)

    hero-portrait.png

Used in the hero section as the large visual on the right side.
**Must have a transparent background** (PNG with alpha channel — a
portrait cutout of just the person, no scenery).

Recommended:
- Aspect ratio: 3:4 or 2:3 (tall) — e.g. 600×800 or 800×1200
- PNG format with transparency
- Under 600KB
- Well-lit, professional, natural photograph with the background removed

The interactive orb moves behind the portrait as a decorative backdrop.
If the PNG is missing, the orb is shown alone (the site never looks broken).

## 2. About portrait (rectangular photo)

    portrait.png

Used in the About section. Standard rectangular photo (background included is fine).

Recommended:
- Aspect ratio: 4:5 — e.g. 800×1000 or 1200×1500
- PNG or JPG
- Under 500KB

If this file is missing, a stylized "Z" placeholder is shown.

## Tips for removing a background

- Use https://www.remove.bg (free, automatic)
- Or GIMP/Photoshop: select subject → invert → delete → export as PNG
- Save with alpha transparency enabled
