# Portrait image

Drop your portrait PNG in this folder with the filename:

    portrait.png

Recommended:
- Aspect ratio: 4:5 (portrait orientation) — e.g. 800×1000 or 1200×1500
- Format: PNG or JPG
- Size: under 500KB for fast loading
- Well-lit, professional, natural photograph

The about section will automatically use this image with a clip-path
mask reveal animation. If the file is missing, a stylized "Z"
placeholder is shown instead.

You can also add `portrait-2x.png` for high-DPI screens (optional).
